# 镜我（Mirror）安装包

这里仅发布镜我 Windows 客户端安装包和自动更新所需的版本文件，不包含项目源代码。

请前往 [Releases](https://github.com/ahaostillcoding/mirror-digital-twin-releases/releases) 下载最新版本。

每次正式发布通常包含：

- `Mirror-<版本号>-Windows-x64-Setup.exe`：Windows 安装程序
- `latest.yml`：客户端自动更新元数据
- `*.blockmap`：增量更新数据

项目源代码在私有仓库中维护。请勿从非本仓库 Release 页面下载或安装镜我客户端。
